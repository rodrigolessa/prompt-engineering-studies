## What is a Prompt Engineering ?

It is a way of designing effective instructions to interact with Artificial Inteligent. It involves continuously refining and improving prompts.

## Whats does Large Language Models (LLMS) stands for?

They are programs trained to understand and generate responses using natural language. Among what they con do are: 
- Answer questions
- Summarize texts
- Create content
